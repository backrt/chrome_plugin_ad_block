AI広告ブロックは、ブラウザで広告リクエストを遮断し、残った広告要素を非表示にする軽量な Firefox アドオンです。

主な機能：
• 静的遮断：同梱の EasyList / EasyList China で一般的な広告ネットワークを遮断
• 要素非表示：化粧ルールの CSS で広告コンテナを隠す
• ページ検出：ポップアップに現在のタブのブロック済みリクエストと疑わしい広告を表示
• ユーザー動的ルール：チェックした項目だけをローカルに保存（ID 1–5000）
• リスト更新：公開フィルターリストの増分を毎日取得（ID 5001–30000）
• ローカル保存：設定とルールは端末内のみ。閲覧履歴は送信しません
• 多言語：简体中文、繁體中文、English、日本語、한국어

使い方：
1. インストール後、通常どおりウェブを閲覧
2. ツールバーアイコンでブロック状況と疑わしい広告を確認
3. 候補を選んで動的ルールに追加し、ページを再読み込み
4. 設定で EasyList / EasyList China と要素非表示を切替、またはリストを手動更新

注意：
• 公開フィルターリスト JSON をデータとしてダウンロードし、リモート JavaScript は実行しません
• アカウントやパスワードは読み取らず、閲覧履歴もアップロードしません
• 動的ルールはこの端末でのみ有効です
