AI广告拦截是一款轻量 Firefox 附加组件，用于在浏览器中拦截广告请求并隐藏残留广告元素。

主要功能：
• 静态拦截：内置 EasyList 与 EasyList China 规则，自动拦截常见广告网络请求
• 元素隐藏：按化妆规则用 CSS 隐藏页面上的广告容器
• 本页识别：在弹窗中列出当前页已拦截请求与疑似广告候选项
• 用户动态规则：由你勾选后才写入本地动态规则（ID 1–5000）
• 列表增量：每日拉取公开过滤列表增量（ID 5001–30000）
• 本地存储：设置与规则保存在浏览器本地，不上传浏览记录
• 多语言界面：支持简体中文、繁体中文、English、日本語、한국어

使用步骤：
1. 安装扩展后正常浏览网页
2. 点击工具栏图标查看本页已拦截与疑似广告
3. 勾选候选项并加入动态规则，刷新页面后生效
4. 在设置页开关 EasyList / EasyList China 与元素隐藏，或手动更新过滤列表

说明：
• 扩展会下载公开过滤列表 JSON 作为数据，不会执行远程 JavaScript
• 不会读取你的账号、密码，也不会上传浏览历史
• 动态规则仅在本机生效
