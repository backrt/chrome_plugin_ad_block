AI廣告攔截是一款輕量 Microsoft Edge 擴充功能，用於在瀏覽器中攔截廣告請求並隱藏殘留廣告元素。

主要功能：
• 靜態攔截：內建 EasyList 與 EasyList China 規則，自動攔截常見廣告網路請求
• 元素隱藏：依化妝規則以 CSS 隱藏頁面上的廣告容器
• 本頁辨識：在彈出視窗列出目前頁面已攔截請求與疑似廣告候選項目
• 使用者動態規則：由你勾選後才寫入本機動態規則（ID 1–5000）
• 清單增量：每日擷取公開過濾清單增量（ID 5001–30000）
• 本機儲存：設定與規則保存在瀏覽器本機，不上傳瀏覽紀錄
• 多語言介面：支援簡體中文、繁體中文、English、日本語、한국어

使用步驟：
1. 安裝擴充功能後正常瀏覽網頁
2. 點擊工具列圖示查看本頁已攔截與疑似廣告
3. 勾選候選項目並加入動態規則，重新整理頁面後生效
4. 在設定頁開關 EasyList / EasyList China 與元素隱藏，或手動更新過濾清單

說明：
• 擴充功能會下載公開過濾清單 JSON 作為資料，不會執行遠端 JavaScript
• 不會讀取你的帳號、密碼，也不會上傳瀏覽歷程
• 動態規則僅在本機生效
