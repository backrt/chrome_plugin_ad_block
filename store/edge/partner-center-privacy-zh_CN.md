## 单一用途描述（≤1000 字）

```
本扩展的唯一用途是：在 Microsoft Edge 浏览器中拦截广告请求并隐藏残留广告元素。

扩展使用内置 EasyList / EasyList China 静态规则拦截常见广告网络请求，按化妆规则用 CSS 隐藏广告容器，并在弹窗中列出当前页已拦截请求与疑似广告候选项。用户勾选后才写入本地动态规则。扩展还会定期下载公开过滤列表 JSON 作为数据以更新增量规则。设置与规则仅保存在用户设备本地。不提供与广告拦截无关的功能。
```

---

## declarativeNetRequest — 许可理由

```
declarativeNetRequest 用于执行广告拦截：加载内置 EasyList / EasyList China 静态规则集，以及用户勾选后写入的动态规则、公开列表增量规则。扩展据此拦截广告网络请求，不修改网页正文，不用于与广告拦截无关的流量控制。
```

---

## 存储 — 许可理由

```
storage 权限用于在浏览器本地保存设置（如是否启用 EasyList / EasyList China、元素隐藏）、用户动态规则、过滤列表缓存与更新状态。数据仅存储在用户设备上，供弹窗与设置页读取。卸载扩展后由浏览器按扩展存储规则处理。不向开发者服务器上传存储内容。
```

---

## unlimitedStorage — 许可理由

```
unlimitedStorage 用于本地保存过滤列表缓存与动态规则。公开列表转换后的规则与化妆表体积较大，普通 storage 配额可能不足。数据仍只留在用户设备，不上传。
```

---

## 警报 — 许可理由

```
alarms 权限用于每天触发一次本地定时任务，从公开地址拉取过滤列表增量 JSON（规则数据），以更新列表动态规则与元素隐藏表。该任务不执行远程代码，也不上传用户浏览数据。
```

---

## activeTab — 许可理由

```
activeTab 用于用户点击工具栏图标打开弹窗时，读取当前标签页近期被拦截的请求，以便在「本页已拦截」中展示。仅在用户主动打开弹窗时使用，不在后台持续读取标签页。
```

---

## webRequest — 许可理由

```
webRequest 权限用于观察未被静态/动态规则拦截的请求，以便在弹窗中列出「本页疑似广告」候选项，供用户勾选后写入动态规则。扩展不修改、不重定向请求正文，也不把请求数据发送到开发者服务器。
```

---

## 主机权限 — 许可理由

```
host_permissions（<all_urls>）是广告拦截所必需的：静态/动态规则需匹配任意站点上的广告请求；content script 需在打开的页面上隐藏广告元素并识别候选项；webRequest 需观察当前页未被拦截的请求。扩展不会将浏览数据发送至外部服务器。若无此权限，将无法实现「拦截广告并隐藏残留广告位」这一核心功能。
```

## 您使用的是远程代码吗？

**选择：否，我未使用远程代码**

理由（若必填可填）：

```
本扩展所有 JavaScript 均包含在提交包内，运行时不会从远程服务器下载或执行脚本。会定期下载公开过滤列表 JSON，仅作为规则数据加载到 declarativeNetRequest / 元素隐藏表，不使用 eval、new Function 或远程脚本注入。
```
