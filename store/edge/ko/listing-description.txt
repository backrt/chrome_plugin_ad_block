AI 광고 차단은 브라우저에서 광고 요청을 차단하고 남은 광고 요소를 숨기는 가벼운 Microsoft Edge 확장입니다.

주요 기능:
• 정적 차단: 포함된 EasyList / EasyList China 규칙으로 일반적인 광고 네트워크 요청을 차단
• 요소 숨기기: 화장 규칙 CSS로 남은 광고 컨테이너를 숨김
• 페이지 감지: 팝업에 현재 탭의 차단 요청과 의심 광고를 표시
• 사용자 동적 규칙: 선택한 항목만 기기에 저장(ID 1–5000)
• 목록 업데이트: 공개 필터 목록 증분을 매일 가져옴(ID 5001–30000)
• 로컬 저장: 설정과 규칙은 기기에만 남고 방문 기록은 업로드하지 않음
• 다국어: 简体中文, 繁體中文, English, 日本語, 한국어

사용 방법:
1. 설치 후 평소처럼 웹을 탐색
2. 도구 모음 아이콘에서 차단 항목과 의심 광고 확인
3. 후보를 선택해 동적 규칙에 추가한 뒤 페이지를 새로고침
4. 설정에서 EasyList / EasyList China와 요소 숨기기를 켜거나 필터를 수동 업데이트

안내:
• 공개 필터 목록 JSON을 데이터로 다운로드하며 원격 JavaScript는 실행하지 않습니다
• 계정·비밀번호를 읽지 않으며 방문 기록도 업로드하지 않습니다
• 동적 규칙은 이 기기에서만 적용됩니다
